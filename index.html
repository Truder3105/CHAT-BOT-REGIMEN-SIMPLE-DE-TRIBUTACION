Gestión tributaria y facturación electrónica para el RST

Desde la expansión de la facturación electrónica en Colombia (2019–presente), los empresarios del Régimen Simple de Tributación (RST) requieren herramientas claras, seguras y accesibles. Este proyecto integra gestión del conocimiento, automatización y una experiencia web moderna.

Problemática

Retos reales del cumplimiento RST

Ilustración conceptual: barras y nodos que representan fricción administrativa y dispersión de información.

📋 Procesos manuales

Planillas y validaciones a mano incrementan errores en campos críticos del XML.

📉 Desconocimiento normativo

Resoluciones y tablas RST cambian; sin educación continua, el empresario opera con incertidumbre.

⏱️ Tiempo documental

Búsqueda de soportes y conciliaciones consume horas que podrían destinarse al negocio.

💸 Riesgo de sanciones

Inconsistencias entre libros y factura electrónica pueden generar observaciones DIAN.

🔧 Herramientas poco accesibles

Soluciones costosas o complejas excluyen micronegocios que también deben cumplir.

Solución propuesta

Automatización con trazabilidad y seguridad

Un flujo claro desde la captura de datos hasta el archivo en nube, con validaciones y reportes.

⚡ XML validado

Plantillas alineadas a XSD y controles de consistencia.

🔄 RST automatizado

Tablas, calendario y recordatorios orientados al usuario.

☁️ Nube AWS

Respaldo, cifrado y escalabilidad modular.

Módulos del sistema

Diez pilares funcionales

Cada módulo se describe con beneficios, tecnologías y un caso de uso.

Emisión controlada con plantillas UBL/DIAN y trazabilidad de eventos.

XMLNode.jsValidación

Caso de uso: ferretería con alto volumen de ventas diarias.

Cálculos y tablas según ingresos; educación contextual para autonomía informada.

MySQLReportes

Caso de uso: PYME de servicios con múltiples responsables.

Índices, versiones y búsqueda rápida de soportes y facturas.

S3Metadatos

Caso de uso: auditoría interna mensual.

CRM ligero con datos tributarios clave y consentimiento explícito.

API RESTPrivacidad

Caso de uso: cartera recurrente de contratos.

Serialización, namespaces y pruebas contra esquemas oficiales.

XSDTests

Caso de uso: lote nocturno de facturas.

Integración PKI con certificados X.509 y sellado de tiempo cuando aplique.

PKIKMS

Caso de uso: factura con firma coherente ante validador.

Defensa en profundidad: TLS, AES-256, RBAC y JWT.

TLS 1.3bcrypt

Caso de uso: roles separados contador/admin.

Exportaciones CSV/PDF y paneles de cumplimiento.

Dashboards

Caso de uso: cierre de periodo.

S3 con políticas de acceso y versionado; integración futura con pipelines.

AWS

Caso de uso: respaldo inmutable de XML firmados.

Conectores para validación y eventos oficiales cuando el modelo lo permita.

Roadmap

Caso de uso: envío validado con reintentos idempotentes.
